# Featured Projects

## 🐄 Mifugo AI

**Offline, Gemma powered livestock triage assistant for smallholder farmers in Kenya.**

Mifugo AI was developed during the **Build with Gemma: Comeback Sprint Hackathon by GDG UoN**, under the **Local Impact and Edge AI** track.

The idea was to explore how an offline AI system could support smallholder farmers when veterinary access is limited. The system accepts descriptions and photographs of livestock and uses a locally running **Gemma model through Ollama** to extract useful observations from Swahili, English, and code switched input.

The important design decision was separating what AI should handle from what should remain deterministic. Gemma handles language and visual interpretation, while Python handles safety critical rules such as isolation, escalation, movement guidance, and human health warnings.

The system was designed to refuse cases outside its defined scope rather than confidently guessing.

### Key ideas

- Offline inference
- Swahili first interaction
- Code switched language support
- Local Gemma model through Ollama
- Deterministic safety rules
- Human health escalation
- Livestock isolation guidance
- Edge AI for resource constrained environments

**Built with:**  
`Python` · `Gemma` · `Ollama` · `AI` · `Computer Vision` · `Edge AI`

## 🎮 Multiplayer Tic Tac Toe

A multiplayer version of a familiar game that became an experiment in **shared application state, databases, SQL, and deployment**.

The project helped me understand what changes when an application is no longer running only for one person and multiple players need to interact with the same persistent state.

It involved connecting the application interface with a backend data layer, managing game state, handling player interactions, and making the application accessible online.

**Built with:**  
`Python` · `Streamlit` · `Supabase` · `SQL`

## 📊 Personal Finance Analysis

An exploratory data analysis project using **1,500 transactions across 60 months** to examine income, expenses, cash flow, and financial behaviour.

The project moves from raw transaction records toward measurable patterns and questions, using visualisation and statistical exploration to understand what the numbers actually reveal.

**Built with:**  
`Python` · `Pandas` · `NumPy` · `Matplotlib`
